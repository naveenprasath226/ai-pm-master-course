# AI for Project & Technical Program Managers — Master Course

A self-paced, milestone-based AI course for PMs, TPMs, Delivery Managers and Implementation Leaders.

## GitHub Pages
This repository is designed to be served as a static site. The course is in `index.html`.

## Course path
AI foundations → ML → Deep Learning → Transformers → LLMs → Prompting → RAG → Tool calling → MCP → Agents → Enterprise architecture → Security/evaluation → AI PM mastery → Capstone.

## Usage
Open the deployed Pages URL in Chrome. Progress is stored locally in the browser via localStorage.
